# DevOps & Cloud Computing Learning Journey 🚀

Welcome to my DevOps and Cloud Computing repository! This space tracks my hands-on labs, automation projects, and infrastructure tasks during my 45-day summer internship .

## 🛠️ Tech Stack & Tools
* **Cloud Platform:** AWS (EC2, IAM, Security Groups)
* **Operating System:** Amazon Linux 2023
* **Version Control:** Git & GitHub (SSH Authenticated)
* **Web Server:** Apache (httpd)

## 📂 Labs & Projects Completed

### 1. Secure Git-EC2 Pipeline
* Configured automated code tracking using Git on an AWS EC2 instance.
* Set up secure **SSH Key Authentication** (`ed25519`) to push code directly to GitHub without passwords.

### 2. AWS Web Server Deployment (`index.html`)
* Deployed an **Apache Web Server (httpd)** on Amazon Linux 2023.
* Optimized **AWS Security Groups** by opening Inbound ports for HTTP (80), HTTPS (443), and Custom TCP (5000) for future Python/Flask apps.
* Hosted a live HTML landing page accessible via the instance's Public IP.
